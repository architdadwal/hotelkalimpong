# Regal Resort & Spa — Website Demo

Modern responsive React + Vite concept website with four pages:
- Home
- Rooms
- Experiences & facilities
- Booking enquiry

## Run locally
1. Install Node.js 18+
2. Open this folder in a terminal
3. Run `npm install`
4. Run `npm run dev`

## Build
`npm run build`

Upload the contents of `dist/` to your hosting provider, or connect this repository to Vercel.

## Booking flow
The homepage booking bar has working check-in/check-out date inputs and guest selection. It passes the selected details to the booking page. The booking form validates the dates and opens an email enquiry addressed to regalresortspa1@gmail.com. This is a demo enquiry only: it does not check live inventory, accept payment or confirm a reservation.

## Property facts used
Room categories, facilities, Samthar location, nearby destinations and contact details are based on the resort's published website (regalstays.in / regalresortspa.com). Rates are intentionally not shown because no fixed rate was confirmed in the source.

## Image note
